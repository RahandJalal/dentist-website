# 🦷 Modern Dental Clinic Website

A full-stack dental clinic web application that allows patients to browse dental services, view doctor profiles, and book appointments online.

---

## ✨ Features

- **Service Catalog:** Overview of clinic services, treatments, and procedures.
- **Online Booking:** Dynamic appointment scheduling form connected to a backend database.
- **Admin & Management:** Database storage for appointments, doctor records, and patient messages.
- **Responsive Layout:** Clean UI adaptable across desktop and mobile devices.

---

## 🛠️ Built With

- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript
- **Local Server:** Laragon (Apache & MySQL)
